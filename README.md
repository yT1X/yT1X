Kiaguri · Uma companhia de outro mundo para o Discord

A Kiaguri nasceu de um problema comum: precisar de vários bots para cuidar de um único servidor. A proposta é reunir os recursos de que uma comunidade precisa em um único bot gratuito, tornando essa experiência mais simples.

Desenvolvo esse projeto desde os meus 15 anos. Nele, coloco ideias em prática, enfrento desafios e aprendo com cada nova etapa. A Kiaguri também tem uma identidade própria: antenas verdes, olhos estrelados e um universo espacial que acompanha sua evolução. 👽💚

Mais do que um projeto para mostrar, ela é parte da minha formação como desenvolvedor.
